# Gestao-de-Chamados
Desafio: criar uma aplicação simples de Gestão de Chamados.

O sistema deve permitir:

* Cadastrar um chamado: título, descrição, solicitante, prioridade, status e data.
* Listar os chamados cadastrados.
* Alterar/editar o status do chamado.
* Filtrar os chamados por status.
* Salvar as informações em um banco de dados.
* Disponibilizar o projeto em um repositório Git.

*Extra:* seria interessante conseguir identificar chamados que estão há muito tempo sem atendimento. Fica a seu critério pensar em como resolver isso.

Pode utilizar pesquisas, documentação, IA, ChatGPT, Copilot ou outras ferramentas que te ajudem. O importante é entender o que foi desenvolvido e conseguir explicar as decisões tomadas.

A linguagem de programação e banco que voce tiver mais facilidade e acesso. 

*Prazo:* 7 a 10 dias, conciliando com suas atividades atuais.

Depois fazemos um papo rápido para você apresentar o projeto, contar as dificuldades que encontrou e explicar as soluções que escolheu.

Não precisa ser algo complexo. A ideia é principalmente ver seu raciocínio, iniciativa e evolução durante o desafio.
